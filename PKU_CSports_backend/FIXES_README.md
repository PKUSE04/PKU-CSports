# 问题修复说明

## 修复的问题

### 1. Picker下拉列表显示问题

**问题**：在设置赛程时，下拉列表显示在页面底层，无法正确下拉选择。

**修复**：
- 在 `tournament-settings.uvue` 中为 `.picker` 添加了 `z-index: 1`
- 在 `.container` 中添加了 `z-index: 0` 确保层级正确
- 修复了球队选择器的实现方式，使用内联picker而不是条件渲染

### 2. 数据中心筛选器无法点击

**问题**：数据中心的年份、赛事类型等筛选器无法点击下拉选择。

**修复**：
- 将 `scroll-view` + `view` 的组合改为使用 `picker` 组件
- 添加了 `onYearChange`、`onTypeChange`、`onGenderChange`、`onStageChange` 方法
- 在筛选选项前添加了"全部"选项
- 为 `.filter-picker` 添加了 `z-index: 10` 确保显示在最上层

### 3. 预设数据更新

**更新内容**：
- 扩展了球队数据：从4支增加到12支（包括联赛组和女子组）
- 扩展了球员数据：从5名增加到21名
- 添加了赛事配置数据：
  - 2024新生杯联赛组（A组、B组）
  - 2024新生杯女子组（A组、B组）
  - 2024北大杯联赛组（A组、B组）
  - 2024北大杯女子组（A组）
- 添加了比赛数据：8场比赛，关联到赛事配置
- 更新了积分榜数据：8支球队的积分数据
- 更新了球员数据：15名球员的进球和助攻数据
- 添加了比赛事件示例：7个事件（进球、黄牌、犯规、换人等）

## 使用方法

### 1. 执行数据库迁移

```bash
# 在WSL或Linux环境下
psql -U postgres -d csports_db -f PKU_CSports_backend/db/migrate_add_tournament_features.sql
```

### 2. 重新初始化测试数据

```bash
cd PKU_CSports_backend
node scripts/seed.js
```

这将创建：
- 测试用户：`testuser` / `123456` (普通用户)
- 协会用户：`assoc` / `123456` (协会用户)
- 12支球队（8支联赛组，4支女子组）
- 21名球员
- 4个赛事配置（新生杯/北大杯 × 联赛组/女子组）
- 8场比赛
- 积分榜和球员数据
- 比赛事件示例

### 3. 测试功能

1. **数据中心页面**：
   - 使用picker下拉选择年份、赛事类型、性别分组、阶段
   - 查看积分榜、球员数据、球队数据

2. **赛制设置页面**（协会账号）：
   - 创建/编辑赛事配置
   - 设置分组情况
   - picker可以正常下拉选择

3. **比赛事件管理页面**（协会账号）：
   - 选择比赛
   - 添加比赛事件
   - 查看和管理事件

## 注意事项

1. 确保数据库迁移已完成
2. 确保seed.js已执行，生成测试数据
3. 如果遇到picker无法显示的问题，检查z-index设置
4. 所有新功能需要协会账号权限才能使用
